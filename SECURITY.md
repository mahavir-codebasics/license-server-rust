# Security Policy

## Supported versions

This project is **pre-1.0**. Security fixes land only in the latest minor
release (and `main`). Older releases do not receive backports.

| Version                  | Supported |
|--------------------------|-----------|
| latest release (`0.x`)   | ✅        |
| earlier releases         | ❌        |

Please include as much of the following as you can:

- Affected version/commit and deployment mode (backend, roles enabled)
- Steps or proof-of-concept to reproduce
- Impact assessment, if known

## Our promise

- We acknowledge reports within **48 hours**.
- We work with you on **coordinated disclosure**: we develop and release a fix
  first, then credit you (if you wish) in the release notes.
- **We will not file issues publicly before a patch ships.**
- Please give us a reasonable window (90 days by default) before public
  disclosure while a fix is prepared.

Thank you for helping keep license-server-rust and its users safe.
